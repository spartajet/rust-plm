# 增量28：非标制造业 Demo 数据包（~100 人公司架构 + 全套演示数据）

> 目标：一键（PLM_DEMO_SEED=1）生成可调试可演示的完整微缩公司——非标自动化行业、约 100 名员工、按部门/角色/密级分布，配套图纸/物料/BOM/关联/检出锁/多生命周期态演示数据。幂等可重跑。
> 分支：`feat/demo-seed`；**迁移 0021（core-sec）**：sec_user.department；无新 crate。

## 设计裁定

### D1 组织架构（100 人，映射到现有角色/密级模型）
系统无部门实体（ORG-01 后置）——demo 用 sec_user.department 列承载部门（迁移 0021），UserAdmin 部门列+筛选。角色仍用三角色+密级（权限模型不膨胀）：

| 部门 | 人数 | 角色/密级 |
|---|---|---|
| 总经办 | 3 | admin×1（总经理=种子 admin 改名）、editor 密级3×2（副总） |
| 机械设计部 | 22 | 部长 editor 密级3；设计工程师 editor 密级2×14；助理 editor 密级1×7 |
| 电气设计部 | 12 | 部长 editor 密级3；电气工程师 editor 密级2×11 |
| 工艺部 | 8 | 部长 editor 密级2；工艺工程师 editor 密级1×7 |
| 生产部 | 18 | 部长 editor 密级2；计划员 viewer 密级1×10；班组长 editor 密级1×7 |
| 质量部 | 10 | 部长 editor 密级2；质检工程师 editor 密级1×5；质检员 viewer 密级1×4 |
| 采购部 | 6 | 部长 editor 密级0；采购员 viewer 密级0×5 |
| 仓储物流 | 5 | 全 viewer 密级0 |
| 销售部 | 9 | 全 viewer 密级0 |
| 财务行政 | 7 | 全 viewer 密级0 |
| 合计 | 100 | （admin 由 ensure_admin 复用为总经理，不重复建） |

- username=`{部门缩写}{两位序号}`（sj01…/dq01…/gy01…/sc01…/qc01…/cg01…/cc01…/xs01…/cw01…）；display_name=`真实中文姓名`（姓池×名池按部门确定性组合）；**统一密码** demo-pass-123（argon2 hash 一次复用批量插入——秒级；台账记：demo 口令统一仅演示环境）。
- 幂等：username 已存在跳过（SQL ON CONFLICT lower(username) DO NOTHING + department 补 UPDATE）。

### D2 演示数据（非标自动化行业，全部走进程内业务服务=真实编码/校验/事件/审计路径）
- **图纸 ~36**（显式编号 DWG-FJS-xxx 三级体系：总装 FJS-ZP-01、部件 FJS-BJ-xx、零件 FJS-LJ-xxx；名称=非标自动化真实语料：环形输送线总装/顶升旋转单元/铝型材机架/伺服电缸/视觉检测治具…）；创建人=机械/电气设计部用户轮换。
- **物料 ~48**：CLS-ZZ 自制（法兰/机架型材/面板/治具板/轴承座…）+CLS-WG 外购（直线导轨/滚珠丝杆/伺服电机/气动三联件/光电传感器/PLC…）——PartService.create 自动赋码（分类规则真实路径）；创建人=采购/仓储。
- **BOM 3 台设备**：总装→部件→零件/物料（深度 3，含外购件跨级复用）——BomStore.set_lines 真实路径（循环校验/闭包表）。
- **生命周期分布**：working 多数；review ×8（设计部提交，提交人轮换）；released ×6（admin 批准，含发布快照）+其中 2 件 revise 出 v2 working；obsolete ×1。
- **检出锁 ×2**：设计部两工程师各检出自己部件图（service.checkout）。
- **关联 ×12**：部件图↔自制物料（doc_part；SQL 直插 obj_link——无副作用链）。
- **种子标记**：sys_param `demo_seeded=version` 完成即整包跳过；audit `demo.seed` 一行。

### D3 触发与接线
`PLM_DEMO_SEED=1`（figment demo_seed: bool 缺省 false）→ main.rs 全服务装配后 `seed::run(SeedCtx{...}).await`（同步等待，日志输出计数+耗时）。e2e 不经 main——`seed::run` 为 pub 且接显式依赖（测试直接构造调用）。

### D4 前端（UserAdmin）
部门列（department）+部门筛选下拉（GET /sec/users?department=sj 服务端筛选）。
