## Global Constraints

- 0016 迁移（core-events——事件域/系统域相邻；0015 已用）：`audit_log(id bigserial, at timestamptz default now(), username text, action text, object text, detail jsonb, trace_id text, ip text)` + 索引 (username,at)/(action,at)/(object)。
- action 词表：`login.ok`/`login.fail`/`doc.view`/`doc.download`/`doc.create`/`doc.update`/`lifecycle.submit|approve|reject|obsolete|revise|release`/`part.create`/`bom.set_lines`/`flow-tier.change`/`webhook.change`/`sec.user.create`/`sec.role.grant|revoke`——中间件兜底 `http`（未显式覆盖的路径：method+path 即 detail）。
- 中间件：成功响应(2xx)即记录（method+path+status+user+trace_id+ip）——action=显式埋点优先，否则 http 兜底；**登录失败/4xx 显式埋点**（安全事件不留痕=盲区）。
- 显式埋点位置：auth.rs（login 成/败）、docs.rs（download/view=GET detail、create）、lifecycle 5 端点经 lc 宏自动（action=action 名）、flow_tier（change）、sec_users（create/grant/revoke）、webhooks（create/delete）、parts（create）、boms（set_lines）。
- 检索端点：`GET /api/v1/audit?username=&action=&object=&from=&to=&page=&size=`（sec:manage 门控；响应信封 {items,total,page,size}）。
- 前端：/admin/audit 页（筛选条+表格+分页），菜单仅 canManageSec。
- 性能：异步 spawn 写入不加延迟（PRD 7.1 API 写延迟预算）；审计表查询走索引。
