# PLM 竞品调研报告（附件 A）

> 服务于《RustPLM 产品需求文档 v1.0》第 2 章的展开材料
> 调研时间：2026-11；调研方式：公开资料（厂商官网、e-works、行业媒体、CSDN 实践文章）+ 行业通用知识梳理

---

## 1. 国内 PLM 市场格局总览

国产 PLM 阵营大致分为四类：

1. **ERP 延伸派**：用友（智石开 PLM Cloud）、金蝶（云星空 PLM / AI PLM）、鼎捷——优势在"业研一体"，PLM 与 ERP 同平台数据贯通；
2. **CAD 同源派**：华天软件（InforCenter，自有三维 CAD）、CAXA 数码大方（电子图板/三维图版）、中望——优势在工具端体验与数据同源；
3. **工艺深耕派**：开目软件（CAPP 起家）、思普（SIPM）——工艺与流程细节深；
4. **国际阵营**：Siemens Teamcenter、PTC Windchill、达索 ENOVIA/3DE、Aras Innovator（开源模式）——功能全、生态深，但实施重、TCO 高、本土响应慢。

市场需求侧趋势（2025–2026）：

- 国产替代与信创加速，制造业自主可控诉求明确；
- 中小企业"图纸管不住、BOM 靠 Excel、变更靠吼"的数字化第一步需求旺盛，但**预算有限、养不起重型系统**；
- 头部企业从 PDM（管图纸）走向 PLM（管全过程：需求-项目-变更-工艺-协同）；
- IPD（集成产品开发）方法论（华为系推广）成为研发管理咨询主流，金蝶等已产品化落地。

## 2. 重点厂商功能与思想分析

### 2.1 用友 PLM Cloud（智石开）——业研一体

**定位**：依托用友 ERP 生态，定位"产品研发管理平台 + 研发/工艺/生产数据桥梁"。

**核心功能**：
- 项目管理与研发数据一体化：ERP 项目设计任务与 PLM 研发任务、输出物关联；
- BOM 多视图：EBOM → 工艺 BOM → MBOM 演进，MBOM 可配置发放至 ERP（U9C）；
- 典型链路：项目建档 → 图文档管理 → 产品设计 → 工艺设计 → MBOM → U9C 资源计划/供应链；
- 研发业务流程与产品数据标准化，落地研发管理体系。

**管理思想**：PLM 是 ERP 的**数据源头**；"设计制造一体化"，变更与 BOM 发布直达生产。

**对本产品启示**：
- BOM 发布到 ERP 的链路（映射、日志、对账）必须产品化（→ BOM-11、INT-03）；
- 项目任务与研发对象（图纸/BOM 作为交付物）的关联模型值得继承（→ PM-03）。

### 2.2 金蝶云星空 PLM / 金蝶 AI PLM——云原生 + IPD

**定位**：基于苍穹云原生 PaaS，以 IPD 流程体系与 V 模型（正向研发）为核心框架，入选 Gartner PLM 市场指南。

**核心功能**：
- IPD 专属能力：市场需求管理（$APPEALS 类评估）、产品规划、Charter（项目任务书）、阶段评审门径；
- CBB（共用构建模块）管理，支撑平台化/模块化设计复用；
- EBOM 审定后直接传递 ERP；PLM+ERP+MES 一体化（同平台）；
- 与主流二三维 CAD/EDA 双向集成；AI 能力（辅助查询/生成）。

**管理思想**：IPD（市场驱动、跨部门团队、阶段门投资决策）+ V 模型正向研发；"研发是端到端流程"而非工具集合。

**对本产品启示**：
- 阶段门（Stage-Gate）评审与检查单模型（→ PM-04）是项目模块的灵魂，不是甘特图；
- CBB/优选库（→ PART-06）体现"复用降本"思想，应做成轻量可用；
- 需求管理作为 V2.0 方向（RQM 模块），先预留对象模型。

### 2.3 华天软件 InforCenter——三维 CAD+PLM 全线

**定位**：山东济南老牌，自有三维 CAD/CAM 内核，PDM/PLM/CAPP/MES 全线产品。

**核心功能（9.x 版本模块清单）**：
- PDM 核心：零部件管理、图文档管理、BOM 管理；
- 工艺 BOM：基于设计 BOM 创建工艺 BOM，工艺合件/拆件、毛坯件/工艺过程件、多工艺 BOM 视图；
- CAPP：典型路线库、工艺设计；
- 工程配置、设计变更、项目进度管理；
- 与自主三维 CAD 深度集成，可提取整套二维图纸。

**管理思想**：CAD 与 PLM **数据同源**（设计工具即数据入口）；工艺视角的 BOM 演进（不只是设计视角）。

**对本产品启示**：
- PBOM 的"合件/拆件/毛坯/过程件"操作模型是制造业真实刚需（→ CAPP-02），V1.5 必须覆盖；
- "CAD 端无感检入"体验（→ 场景 S1、DES-01/02）是设计员接受度的生死线。

### 2.4 开目软件 KmPLM——工艺起家的中小企方案

**定位**：武汉，CAPP 工艺设计起家二十年，PLM 强调"易用性、低成本、快速见效、易部署、可扩展"，主打中小企业与装备制造。

**管理思想**：**快速见效**——降低实施门槛与总拥有成本，是国产阵营中"轻量化"路线的代表。

**对本产品启示**：轻量部署/快速见效与本项目"敏捷高效"卖点同源，但开目受限于传统技术栈；Rust 单二进制可在此维度形成代差（→ 1.3 节 F3、A1）。

### 2.5 CAXA PLM（数码大方）——图档管理扎实

**定位**：自主二维/三维 CAD（电子图板/三维）+ PLM，"设计-工艺-制造-管理"完整链条。

**核心功能**：工程图档管理、设计变更控制（CAD 原生场景扎实）、国产 CAD 用户基数大。

**对本产品启示**：国产 CAD（中望/CAXA）集成的优先级应高于 Creo/NX（→ 6.9.1 机械矩阵），这是差异化人群。

### 2.6 其他

- **鼎捷 PLM**：装备制造行业深耕，与鼎捷 ERP 打通；
- **思普 SIPM**：流程与实施方法论细；
- **三品 PLM**：中小企图文档/BOM 起步方案；
- **中望 PLM**：CAD 厂商向管理延伸的新军。

## 3. 共性功能底座（Capability Matrix）

对上述产品功能取并集与交集，得到国内 PLM **必须具备的公共功能集**（交集）与**差异化功能**（并集减交集）：

### 3.1 公共功能集（各家全有 → 我们 P0/P1 必做）

| 域 | 功能点 |
|---|---|
| 图文档 | 类型管理、检入检出、版本、权限、在线预览/PDF、圈阅签名、审批发布、批量导入 |
| 物料 | 类型分类、属性、申请审批、查重、编码规则 |
| BOM | EBOM 编辑、CAD 生成 BOM、版本、对比、汇总报表、多视图（EBOM/PBOM/MBOM） |
| 变更 | PR/ECR/ECO/ECN 链路、影响分析、断点（各家深度差异大） |
| 流程 | 可视化/模板化审批流、会签或签、电子签名、出差代理、催办 |
| CAD 集成 | SolidWorks/AutoCAD/Creo/NX 至少 2–4 种 + 国产 CAD |
| 项目 | 立项、WBS、甘特、任务、交付物关联、阶段评审 |
| 检索报表 | 属性检索、全文检索（各家强弱差异大）、台账报表 |
| 平台 | 组织权限（RBAC+数据权限）、编码系统、审计、与 ERP 集成 |

### 3.2 差异化/增强功能（部分家有 → 我们按版本规划）

工艺 CAPP 深度（开目/华天）、IPD/需求管理（金蝶）、变型配置 BOM（Windchill/Teamcenter）、供应商协同（Teamcenter/SAP）、EDA 集成（金蝶）、MES 打通（金蝶/鼎捷）、3D 可视化对比（Teamcenter/Windchill）。

### 3.3 行业普遍短板（我们的机会窗）

| 短板 | 现状证据 | 我们的机会 |
|---|---|---|
| 实施周期长 | 行业普遍数月至一年；"90% PLM 项目达不到预期"（e-works） | 7 天基础包上线（A1）+ 行业模板包（A3）+ 配置中心（AGL） |
| 技术栈重 | Java/.NET + 中间件 + 多节点；内存占用高；中小企运维不起 | Rust 单二进制 4C8G 起步（F3） |
| 二开依赖 | 流程/表单改动需厂商开发，升级破坏定制 | 全链路配置热生效（A2）+ Aras 式元数据模型 |
| 性能 | 大 BOM 展开、批量操作、检索慢是高频抱怨 | 图式 BOM 引擎 + tantivy 全文 + 性能门禁（F1） |
| 变更脱节 | EBOM 与工艺 BOM 脱节、ECN 不同步导致批量质量事故（公开案例） | 联编联动 + 断点管理（EC-05/07） |

## 4. 设计软件生态调研（支撑主文档 6.9 DES 支持名单）★

> 检索时间 2026-11；结论用于确定"机械/电气/电子"三线集成矩阵的优先级。

### 4.1 机械 CAD（MCAD）

- 中国 CAD 市场 2024 约 61.2 亿元（IDC），国产厂商合计约 27% 且持续上升；
- **SolidWorks**：中端三维领跑（装机占比约 18–32% 区间），**中小企业渗透率最高**——小微机械主力工具之一；
- **AutoCAD**：2D 存量巨大，是历史图纸迁移的主战场（标题栏 OCR 的主要对象）；
- **中望软件**：连续四年本土厂商份额第一（2D 份额 9.1%），2025 年跻身中国市场全球品牌前三——信创/国产替代首选；
- **产品决策**（目标客群国产化导向）：机械**首选中望 2D/3D 首发**，SolidWorks 紧随（次批）；
- **CAXA/华天/浩辰**：国产行列前列，小微存量用户多，V1.5 补齐；
- **Creo/NX/CATIA**（各 9–15% 份额）集中在汽车航空大企业，小微极少——后置 V2.0；
- **Inventor/Solid Edge**：中端补充，按需求排 V1.5/V2.0。

### 4.2 电气 ECAD

- **EPLAN Electric P8**：专业标杆（Data Portal 450+ 制造商/200 万+ 元器件数据，SQL 数据库驱动的工程数据中枢）；**产品决策：电气首选 EPLAN 首发**——目标客群（机电/装备类小微）电气图纸规范化程度高、EPLAN 为专业主力，其开放 API 支持项目归档/部件报表的结构化深度集成；
- **AutoCAD Electrical / SEE Electrical / SolidWorks Electrical**：中小用户主力，AutoCAD Electrical 为 V1.0 电气首发；
- **嘉立创 ECAD**（2024 推出）：在线免费、对标 EPLAN、海量电气部件库、一键 BOM——**小微电气设计快速崛起选项**，且与嘉立创生态（FA-Part/开放平台/云 ERP）天然联动，V1.5 集成并作为特色；
- **利驰 SuperWORKS**：EPLAN 国产平替，长尾按需。

### 4.3 电子 EDA

- **Altium Designer**：中国专业付费主流——V1.0 必做；
- **立创EDA（EasyEDA）**：免费国产，创客与小微硬件团队用户量极大，元件库与立创商城采购直通——**小微硬件第一工具，V1.0 首发**（并与 FA 模块联动形成"设计→选型→打样下单"闭环）；
- **KiCad**：开源、文本格式开放易解析——V1.5；
- **PADS/OrCAD/Allegro**：高速板/大企业场景——V2.0。

| 线 | 首发（V1.0） | 第二批（V1.0 次批/V1.5） | 后置（V2.0） |
|---|---|---|---|
| 机械 | **中望 CAD/中望 3D（首选）**、AutoCAD | SolidWorks（V1.0 次批）、CAXA、Inventor（V1.5） | Solid Edge、Creo、NX、CATIA |
| 电气 | **EPLAN Electric P8（首选）** | AutoCAD Electrical（V1.0 次批）、嘉立创 ECAD（V1.5） | SEE Electrical、SolidWorks Electrical、SuperWORKS |

## 5. FA 工业品商城开放能力调研（支撑主文档 6.19）★

| 平台 | 开放能力（2026-11 检索） | 对接策略 |
|---|---|---|
| 嘉立创（JLC） | **开放平台 open.jlc.com**（正式 API 合作对接）；**FA-Part 3D 零件库**（按型号下载多格式 CAD 模型+跳转购买）；嘉立创云 ERP 生态（API/私有部署）；立创商城元器件（库存/价格/封装数据，与立创 EDA 打通） | 官方 API 合作优先；元器件深度联动（FA-07）为重点闭环 |
| 怡合达（YIHEDA） | **开放平台 open.yiheda.com**：标准零部件数据 + 一站式选型采购协作，支持 API 对接 | 官方 API 优先，非标零部件结构化选型主源 |
| 米思米（MISUMI） | 官网 CAD 数据（DXF 等）与选型手册下载为主，**公开 API 较少** | 目录导入兜底（选型表/链接/OCR），关注其官方 API 进展 |
| 其他（震坤行/固安捷/海智在线等） | 开放程度不一 | 经 PLUGIN 插件生态扩展（FA-01 连接器框架） |

**结论**：采取"**官方 API 优先 + 目录导入兜底 + 插件生态扩展**"三级策略；嘉立创与怡合达建立官方合作关系（V1.5 首批连接器），米思米先以数据导入方式覆盖。采购侧只生成下单建议/链接、不默认代下单，规避财务合规风险（FA-09）。

## 6. 核心管理思想提炼（本产品的理论根基）

1. **单一数据源（SSOT）**：所有产品数据一处维护、处处引用。Teamcenter/Windchill/国产头部共同的顶层理念；行业项目成败分水岭。
2. **对象-关系元数据模型**：物料、文档、BOM、变更单皆为"业务对象"，类型/属性/关系可配置（Aras 发扬光大）→ 支撑敏捷配置。
3. **以 BOM 为主线的多视图演进**：EBOM（设计）→ PBOM（工艺）→ MBOM（制造），视图间映射可追溯；BOM 是研产数据交接的"界面"。
4. **版本 + 生命周期 + 状态权限三位一体**：Working/Released/Obsolete 状态机；发布即冻结；修改必走变更。
5. **CMII 变更闭环**：PR→ECR→评审→ECO→ECN→断点，影响分析先行，联编联动执行。
6. **流程与数据分离**：流程只管路由与签审，业务规则独立挂接；流程可重编而不动数据。
7. **IPD 研发管理**：市场驱动、阶段门投资决策、跨部门重量级团队、CBB 复用（金蝶已产品化，作为 V2.0 需求管理的输入）。
8. **业研一体**：PLM 是 ERP 的源头（物料/BOM/工艺/ECN 四类主数据下发），集成能力是一等公民而非附属。
