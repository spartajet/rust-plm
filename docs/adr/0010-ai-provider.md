# ADR-0010 AI 网关：Provider trait 抽象，云端/本地双形态可断电

- 状态：已接受（2026-11-11）
- 关联需求：AI-01~04（平台层）、AI-02（数据安全分级）、AI-04（降级）

## 背景

LLM 供给侧高度流动（DeepSeek/Qwen/OpenAI 兼容各家、Ollama/vLLM 本地），且客户对数据出网态度两极。若在业务代码里直连某家 SDK，会同时锁死厂商与安全策略。

## 决策

`svc-ai` 网关统一 `LlmProvider` trait（chat/embed/流式）：`OpenAiCompatProvider`（覆盖所有 OpenAI 协议厂商，仅 base_url+key 差异）与 `OllamaProvider`（本地）两实现；**场景路由表**（OCR→本地小模型、问答→按企业策略）+ **脱敏中间件**（上云前词表替换）+ 全量调用审计；企业级三档安全模式（纯内网/脱敏上云/开放，AI-02）在参数中心一键切换。RAG 依赖 pgvector + tantivy 混合检索（ADR-0005/0008 复用）。

## 后果

- ✅ 换模型零业务代码改动；AI 整体禁用后全部功能人工可达（降级承诺 AI-04）；
- ✅ "纯内网模式"成为对保密敏感客户的卖点而非妥协；
- ⚠️ 本地模型对 2C4G 机器负担重——本地形态标注最低硬件建议（如 8C16G + 量化模型），小内存环境提示走云端脱敏或禁用；
- ⚠️ 各家流式/工具调用协议有细微差异——Provider 适配层测试集固化。
