# ADR-0012 文件库：SHA-256 内容寻址 + 引用计数 GC

- 状态：已接受（2026-11-11）
- 关联需求：DOC-03/09/11、DES-03（秒传/去重/巨量归档）

## 决策

- 存储路径 `vol/{sha256 前 2 位}/{sha256}`，天然去重 + 秒传 + 完整性自校验；
- `file_object(hash, size, mime, virus_status)` 与 `file_ref(object_id, role, hash)` 引用计数分离；零引用孤儿由夜间 GC 清理（先隔离 7 天再删除）；
- 本地分卷（默认）与 S3/MinIO（可选）双实现，同一 FileStore trait；
- 上传分片断点续传；下载经授权签名链接，全量审计。

## 后果

- ✅ 100 万级图纸去重存储（V-1 实测 COPY 37s/百万行支撑导入性能）；
- ⚠️ 大文件哈希计算在服务端流式完成，占 CPU——大文件（>500MB）走客户端预计算 + 服务端抽查校验。
