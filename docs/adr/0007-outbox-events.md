# ADR-0007 事件总线：Postgres Outbox + Webhook 投递

- 状态：已接受（2026-11-11）
- 关联需求：INT-02（Webhook 可靠投递）、EC-05/EC-06（联编联动/变更必通知）、RPT-03（索引近实时）、COL-04（订阅）

## 背景

领域事件（对象发布/升版/变更/流程流转）有三类消费者：外部 Webhook、内部索引器、内部通知。直接在业务事务里同步调用会引入部分失败；无独立 MQ（违背单机部署）。

## 决策

Transactional Outbox：业务事务内写 `event_outbox`（topic/payload/目标）；投递器批量拉取后分发——**内部消费者**（索引/通知/AI 触发）进程内直调，**外部 Webhook** HMAC 签名 POST + 指数退避重试 + 死信表；同一事件多订阅者扇出。消费位点与重试状态均在库内，无独立中间件。

## 后果

- ✅ "发布必通知"有事务保证（EC-06 依赖此语义）；崩溃恢复后不丢事件；
- ✅ 索引近实时（<5s）复用同一通道（ADR-0005）；
- ⚠️ 投递器是唯一后台循环——需幂等（消费者按 event_id 去重）与对账报表兜底；
- ⚠️ 高峰期 outbox 表膨胀——分区 + 已消费归档。
