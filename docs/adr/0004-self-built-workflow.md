# ADR-0004 工作流引擎自研（轻量状态机 + BPMN 子集）

- 状态：已接受（2026-11-11）
- 关联需求：WF-01~09（尤其 WF-07 热更新、WF-08 <200ms 流转）

## 背景

Rust 生态无生产级 BPMN 引擎（Zeebe 是 Java/独立服务，破坏单体内嵌目标；现成 Rust 工作流库面向临时编排而非持久审批流）。PLM 审批流模式收敛：审批/会签/或签/条件/并行/子流程/定时器，复杂事件网关等 BPMN 全集并不需要。

## 决策

自研：流程定义 = BPMN 2.0 XML 子集（前端 bpmn-js 渲染）+ 版本化存库；执行 = 令牌状态机解释器（每实例持久化 `current_nodes`）；节点办理人解析器（角色/上级/表单取人）独立可扩展；**热更新**：实例绑定启动时模板版本，迁移工具生成新旧节点映射后批量改写（策略可配，WF-07）。

## 后果

- ✅ 单库事务内流转（<200ms 可达，WF-08）；完全掌控热更新/回退语义；
- ✅ 子集明确：不支持的 BPMN 元素导入时显式报错而非静默降级；
- ⚠️ 自研成本约 2~3 人周（含设计器联调）——MVP 先上"表单化模板配置"，图形化设计器 V1.0 交付（版本规划已排）；
- ⚠️ 需补基准：1 万在途实例的流转延迟回归测试进 CI。
