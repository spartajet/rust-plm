# ADR-0018 DWG→PDF：插件端转换起步，服务端转换后置

- 状态：已接受（2026-11-11，选型批次 3）
- 关联需求：DOC-02/05、VIS-01

## 背景

DWG→PDF 服务端转换三条路线：ODA 商业 SDK（质量金标准，年费数千美元级）、开源链（DWG→DXF→开源渲染，复杂图保真风险高）、云 API 按量（变动成本 + 内网不可用）。目标客群（小微、图纸保密敏感、价格敏感）下三条路线都有硬伤。

## 决策

**V1.0 采用"插件端转换"**：DES 插件（AutoCAD/中望）在本机调用 CAD 本体的批量发布能力生成 PDF，随图纸检入一并上传（保真度 100%、零授权费、内网友好）；PLM 服务端只接收 PDF 并索引/水印。**V1.5+ 按需补服务端转换**：对无 CAD 环境的批量历史迁移场景，评估 ODA 授权（成本分摊到企业版）或按量云 API（外网客户可选）。

## 后果

- ✅ MVP 零授权成本、保真无风险、离线可用；
- ✅ 批量历史迁移 V1.0 可用"借一台装 CAD 的机器跑批量工具"方案覆盖；
- ⚠️ 预览依赖设计端习惯（上传者须装 CAD 插件）——存量图纸无 CAD 环境时预览缺失，销售与实施话术需明示；AI OCR（PaddleOCR）不受影响（识别的是标题栏区域）；
- ⚠️ Office→PDF 走 LibreOffice headless（svc-convert）不受本决策影响。
