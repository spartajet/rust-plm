# RustPLM 演示指南（非标自动化行业 · 100 人公司微缩）

> 一键生成：`PLM_DEMO_SEED=1` 启动服务即幂等生成（已生成再启动自动跳过）。
> 统一口令：`demo-pass-123`（**仅演示环境**——生产部署严禁开启 PLM_DEMO_SEED）。
> 生成量：100 名员工（十部门）+ 36 张图纸 + 48 项物料 + 5 棵 BOM 树 + 8 张评审中图纸 + 7 张已发布快照 + 2 把检出锁 + 12 条物料↔文档关联。

## 三、演示动线（五幕）

1. **组织与权限（3 分钟）**：admin 登录 → 用户管理：部门筛选"机械设计部"22 人、部门列展示；切 sj01 登录（editor 密级 2）→ 无用户管理菜单。
2. **编码与建档（3 分钟）**：sj01 登录 → 物料：新建自制件"定位块 2.0"→ 自动赋码 WL-ZZ-00029；查重提示同类件。
3. **图档与审批（5 分钟）**：图纸列表筛选"审核中"8 张 → 打开 review 件 → 审批意见"同意发布"→ 批准 → released；待办中心清空一条。
4. **BOM 与追溯（4 分钟）**：DWG-FJS-ZP-01 详情 → BOM 展开（跨级外购导轨×12）→ 关联物料卡 12 条 → 物料侧反查图纸。
5. **安全与审计（4 分钟）**：DWG-FJS-BJ-104 锁横幅（黄文涛检出中）→ admin 强制解锁；密级 2 件对 viewer 不可见；审计日志过滤 login.fail / doc.checkout。

## 四、调试要点

- 幂等：`demo_seeded` 标记在 sys_param；重跑服务/重启不重复生成。清库重建即整套重来。
- 登录任意员工：`{账号}` / `demo-pass-123`；admin 口令为启动时 `PLM_ADMIN_PASSWORD`（demo 容器建议也设为 demo-pass-123 统一）。
- seed 耗时约 3-5 秒（100 argon2 复用单 hash + 全业务路径创建）；日志输出计数行"Demo 数据包生成完成"。
